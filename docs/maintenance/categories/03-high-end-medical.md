# 💎 高端醫療 (High-End Medical) 維護手冊 (03-high-end-medical)

> **定位宗旨**：專門收錄全數賠償、尊貴私家房、大額醫療保障旗艦產品（共 10 款）。專為需要「突破細項限制、全球頂尖名醫」嘅客戶打造。新手 30 秒上手指南！🚀

## 🎯 類別定位與維護核心心法

1. **「全數賠償 (100% Full Cover)」精神**：
   - 高端醫療最核心嘅靈魂：**「住院及手術費用不設個別分項細項封頂（No Sub-limits）」**！
   - 無論病房費幾貴、名醫開刀手術費幾多、雜費開支幾高，只要係合資格醫療開支，均於自負額過後 **100% 實報實銷**，直至「每年限額」或「終身限額」。
2. **自負額（Deductible / Excess）玩法**：
   - 普遍設有 HK$0、HK$16,000、HK$20,000、HK$25,000、HK$50,000、HK$80,000 等檔次。
   - **關鍵核心**：自負額係**「每保單年度累計（Per Policy Year）」**，而**唔係**「每宗傷病（Per Condition）」！全年所有住院合資格開支加埋超過自負額之後，剩餘全部由保險公司賠足。
3. **地域限制與房間級別懲罰（Downgrade Penalty）**：
   - 地域通常劃分：亞洲／亞洲及澳紐／全球除美／全球。
   - 房型通常劃分：標準半私家房（Semi-Private）或標準私家單人房（Standard Private）。
   - **地雷警告**：若受保人購買「亞洲」卻在美國非緊急就醫，或購買「半私家房」卻自選入住「私家房/套房」，保司會按條款啟動「賠償比率調整（Adjustment Factor）」，通常直接被扣減至只賠 50% 至 80%！
4. **天價保障與終身保證續保**：
   - 每年保額介乎 **HK$1,000 萬至 HK$4,000 萬**，終身保額不設上限或高達 **HK$8,000 萬至 1 億港元**。
   - 一律**終身保證續保**（Guaranteed Renewable for Life），不因索償歷史而加 Loading 或拒保。
5. **出院免找數（Cashless Guarantee）**：
   - 經保司或其第三方救援機構預先批核（Pre-authorisation）後，保司直接向私家醫院支付賬單，受保人免墊支、免填 claim 表出院。

## 🛠️ 常規更新步驟 (Step-by-Step SOP)

### 1. 遇到保費變更點改？
1. 打開 `public/data/insurance-data.json`。
2. 尋找對應的高端醫療 ID（例如 `"id": "high-end-bowtie-pink"`）。
3. 檢查並更新：
   - `premium_range`：填寫典型自負額檔次下的年繳保費範圍（例如：`每年 HK$4,800 – 38,000（視乎年齡及自負額）`）。
   - `premium_notes`：註明自負額可選金額（如 HK$0 / HK$16,000 / HK$20,000 / HK$80,000）及扣稅優勢。
   - `plan_tiers`：確保各房型與保額級別（普通房／半私家／標準私家）描述準確。

### 2. 遇到保險公司更新 PDF 條款點換？
1. 下載官方最新產品小冊子或保單條款 PDF。
2. 將檔案放入 `public/docs/brochures/`（例：`axa-global-elite-2026.pdf`）。
3. 執行雜湊登記指令：
   ```bash
   node scripts/build_pdf_manifest.mjs
   ```
4. 在 `insurance-data.json` 中更新引用：
   - 將該產品對應項目嘅 `source_url` 改為新檔名及頁碼。
   - 核對每年限額、終身限額、自負額等數字，必須與 PDF 該頁完全一致。

### 3. 邊啲常見誤區千祈唔好踩？⚠️
- ❌ **誤區一：以為自負額係「每次手術/每次入院」扣一次！**
  - 大錯特錯！高端醫療嘅 Deductible 係**「按保單年度累計 (Per Policy Year)」**。同一年內即使入 5 次院，自負額都只扣一次！切勿向客戶傳達錯誤訊息！
- ❌ **誤區二：忽略「越級降額懲罰」條款！**
  - 客人如果買半私家房計劃，貪舒服擅自住咗頭等私家房，保險公司**絕唔會**賠足再扣差價，而係會按條款直接打折（通常只賠 50%-70%）！更新時必須保留房型級別說明。
- ❌ **誤區三：誤將非自願醫保的高端醫療寫成「可扣稅」！**
  - 並非所有高端醫療都係自願醫保（VHIS）！例如 Bupa Global Elite、Cigna Global 等純國際醫療保單無 VHIS 認可編號，**不能申請政府扣稅**；而 Bowtie Pink、富衛尊衛您則屬於 VHIS 靈活計劃，**可以扣稅**。切勿盲目標註可扣稅！
- ❌ **誤區四：將精神科或門診透析分項限制漏記！**
  - 即使係「全數賠償」計劃，精神科住院（Psychiatric Treatment）通常仍設有專項每年上限（如 HK$30,000 - $100,000），切忌全單籠統標註為「無上限」。

## 🧪 測試與驗收 Command

修改任何資料後，必須跑足以下 5 大檢驗程序：

```bash
# 1. 檢查 PDF 鏡像雜湊清單（若有加減或換 PDF）
node scripts/build_pdf_manifest.mjs --check

# 2. 單元與資料庫驗證
npm test

# 3. 代碼風格與類型檢查（零警告通行）
npm run lint -- --max-warnings=0

# 4. 篩選組合與邊界邏輯測試
npm run test:filters

# 5. 生產構建測試
npm run build
```

🎯 5 個綠掣全齊，即可提交 PR！
