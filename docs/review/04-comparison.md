# 比較準確性與摘要命中

已修復可重現案例：不保障／不適用／待確認／零保障額不再因出現關鍵字算命中；計劃名稱不當保障依據；排除條款提及同一特點時保守地要求人工核對。重複 tag id 去重。租車自負額關鍵字移除一般「自負額」以免把其他自負額誤算租車保障。

金額只解析一個明示 HKD 數字。多金額、區間、不同幣種、附帶其他數字、無上限都不冒算。最佳高亮需要每欄完整、明示相同 year/lifetime/day/trip/event 單位，自負額取低值而非高值。

移除無可靠同條件基準的全產品最高保額及 CP score 排序；例如將第三者責任的大額上限當醫療保障優勢，或將無上限映射為虛構十億，都不合理。保留摘要排序與參考保費，並清楚標示不是報價或適合度。

新4組回歸測試先在舊實作全數失敗，修復後全數通過。保守規則會產生較多 unknown，這比把排除條款當承保安全，但不是完整自然語言保單解讀。嚴格模式的舊 fallback 保留相容性，介面明確標示以下只係不符合全部条件的替代資料。後續應以逐條人工審核、結構化 benefits/eligibility schema 取代文字啟發式。
